What it does

⌕

Search anywhere

All drives, a single drive, Desktop, Documents, Downloads, or any folder you pick.

≡

Basic type filters

Documents, Images, Videos, Audio, Archives, Code, Executables. Toggle any mix, or search everything.

*

Partial names and wildcards

report finds every file with "report" in the name. *.pdf and inv??ce* work too.

⏱

Size and date filters

Only files over 10 MB, only files changed in the last 7 days, and so on.

▶

Live results

Matches appear while the scan is still running. Stop at any time. Sort by any column.

↗

Open in one click

Double-click to open a file. Right-click to open its folder or copy the full path.

How to use it

  1. Download QuickFileSearch.exe and run it. There is no installer.
  2. Type part of a file name in the search box, or leave it empty to list every file of the chosen types.
  3. Pick where to look and which types to include, then press Search or Enter.
  4. Double-click a result to open it. Press Esc to stop a long scan.
Windows SmartScreen may show "Windows protected your PC" the first time, because the exe is not code-signed. Click More info, then Run anyway. The source is open, and you can build the exe yourself from the repository.

Under the hood

Written in PowerShell with Windows Forms, so it runs on every Windows 10 and 11 machine with nothing extra installed. The exe is produced with ps2exe by GitHub Actions on every tagged release. Scanning runs on a background thread, so the window stays responsive. Settings are remembered between runs.
